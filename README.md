# Quirl — Downloads

Hier liegen die fertigen Installationsdateien von **Quirl**, der Kochbuch-App
ohne Konto, Werbung und Tracking. Der Quellcode liegt nicht in diesem Repo.

**Download und Anleitung:** https://quirl.vancheng.de/#downloads

| Plattform | Datei |
|---|---|
| Windows 10/11 (64 Bit) | `quirl-windows-x64.zip` |
| macOS | `quirl-macos.dmg` |
| Linux, alle Distributionen | `quirl-linux-x86_64.AppImage` |
| Linux, Debian/Ubuntu/Mint | `quirl-linux-amd64.deb` |
| Linux, Fedora/openSUSE | `quirl-linux-x86_64.rpm` |

Die neueste Version steht immer unter
[Releases → Latest](https://github.com/bdgraue/quirl-releases/releases/latest).
Android gibt es über Google Play.

# Quirl — Downloads (English)

This repository holds the ready-made installation files of **Quirl**, the
cookbook app without account, ads, or tracking. The source code is not part of
this repository.

**Download and instructions:** https://quirl.vancheng.de/en/#downloads

The latest version is always under
[Releases → Latest](https://github.com/bdgraue/quirl-releases/releases/latest).
